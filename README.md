# YouTube Homepage Clone

A front-end clone of the YouTube homepage created using HTML and CSS. This project recreates the basic layout and visual structure of YouTube's homepage.

## 🛠️ Technologies Used

- HTML
- CSS

## 📌 Features

- YouTube-style navigation bar
- Search bar
- Sidebar navigation
- Video thumbnail grid
- Channel profile images
- Video titles, channel names, views, and upload time
- Links to the corresponding YouTube videos and channels
